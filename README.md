# Subway Surfers — Transilvânia

Build mínima coletada da página pública `https://ashuni.lol/transylvania/`.
Inclui o `index.html` e somente os arquivos que o player realmente requisitou ao chegar ao menu: manifesto, dados, WASM, framework, loader, StreamingAssets, catálogos e bundles específicos do mapa.

Para abrir, sirva esta pasta por HTTP; Unity WebGL não funciona via `file://`.
